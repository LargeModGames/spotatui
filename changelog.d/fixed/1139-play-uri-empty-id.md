- **`play --uri` refuses a Spotify URI with no id before it starts**: `spotatui play --uri spotify:track:` (or any other kind with nothing after the last colon) booted, logged in and only then failed on the play call. It now stops at once with the "expected a spotify:track: ..." message, naming the kind that has no id ([#1139](https://github.com/LargeModGames/spotatui/issues/1139)).
