- **A queued track no longer expires while spotatui waits for the network**: a pending play request is only good for a limited time, but the wait for spotatui to rebuild its native Connect device counted against that time. While spotatui retried a failed rebuild for up to a minute, a request that had been waiting could run out of time and be reported as expired instead of playing. The time a rebuild spent retrying no longer counts against the pending request.
