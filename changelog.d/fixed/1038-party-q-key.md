- **Typing q no longer closes the Listening Party join code or guest name**: the back key reached the runner before the Party popup could read it, so a typed `q` closed the popup and left the half-typed code for the next visit. `q` now types the letter while the join code or the guest name box is up, and still closes the popup on the idle menu ([#1038](https://github.com/LargeModGames/spotatui/issues/1038)).
