- **Playlist sync keeps manual mirror tracks safe after failed adds**, ignores repeat registrations of the same mirror, and gives exact link IDs priority over playlist names. Name filters handle accented capitals, and track matching recognizes equivalent Unicode text and keeps explicit live and acoustic versions distinct. A track removed from the master playlist before upgrading from version 1 of `playlist_sync.yml` stays on the mirror playlist after the first sync because that run drops the migrated pair, so remove the track from the mirror by hand.
