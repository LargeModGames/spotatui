- **A login Spotify no longer accepts is cleared instead of staying cached**: Spotify's login5 rejects a stored credential that has gone bad with `INVALID_CREDENTIALS` or `UNKNOWN_IDENTIFIER`, and spotatui only cleared the cache for the kinds librespot reports as `Unauthenticated` or a plain `PermissionDenied`, so a refused login stayed on disk and every later rebuild or launch failed the same way. A rejected login now clears the cached streaming credentials too, so the next launch asks you to log in again instead of the new retry loop reusing a credential Spotify will not take, while a transient failure keeps the cached login.
