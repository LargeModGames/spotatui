- **A play pressed during an outage no longer starts minutes later**: a playback request that waited for spotatui to reconnect could be kept alive indefinitely, because the retry chain has no time limit and every second it spent waiting was credited back to the request. With the network down for 40 minutes, a play pressed in the second minute still started out loud when the connection returned. A request is now dropped once it is more than two minutes old, however long the retry chain ran, and the status bar says it expired instead.
