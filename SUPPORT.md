# Getting help

- **Questions, install help, ideas:** the [Discord](https://spotatui.com/discord) or [Discussions](https://github.com/LargeModGames/spotatui/discussions).
- **How something works:** the [docs](docs/README.md).
- **A bug:** open a [bug report](https://github.com/LargeModGames/spotatui/issues/new/choose) with a `spotatui --debug` log ([Logging](docs/configuration.md#logging)).
- **A security problem:** follow the [security policy](SECURITY.md), not a public issue.
